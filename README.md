# Классификация писателей

## Цель и задачи
### Цель
Построить модель машинного обучения, способную по отрывку текста корректно определить его автора из заданного списка.

### Задачи
- Очистка и лемматизация текстов, удаление мусорных и служебных слов.
- Векторизация текстов с помощью TF-IDF.
- Обучение нейронной сети-классификатора на полученных признаках.
- Оценка метрик точности на отложенной валидационной выборке.

## Обоснование выбранного подхода
- Обработка данных включает в себя исключение лемматизацию и удаление стоп-слов для уменьшения шума и усиления различия стилей авторов
- Векторизация TF-IDF отличный способ выделить отличительные слова каждого из авторов особенно при работе с текстом с предобработкой. Mаксимальное количество признаков ограниченно 5000 для уменьшения объема данных, а так же используется биграма для учитывания сочетания слов  
- В качестве модели будет использоваться Dense Neural Networks из-за простоты и эффективности при работе с фиксированным размером входных признаков (в моем случае TF-IDF векторами)
  - Используется 3 слоя с уменьшением числа нейронов
  - Используется функция ReLU для активации 
  - Используется регуляризация, чтобы избежать переобучение
  - В качестве выходного слоя Softmax для многоклассовой классификации
  - Из-за того что данные неравномерные добавлены классовые веса, чтобы не было переобучения в сторону классов с большим количеством записей


## Предобработка

```python
def clean_text(text):
    text = text.lower()
    text = re.sub(r"[^а-яa-zё\s]", " ", text)
    text = re.sub(r"\s+", " ", text).strip()
    tokens = text.split()
    tokens = [t for t in tokens if t not in russian_stopwords]
    lemmas = [morph.parse(token)[0].normal_form for token in tokens]
    return " ".join(lemmas)
```

Все тексты переводятся в нижний регистр, удаляются лишние символы и стоп-слова, проводится лемматизация.

## Модель и её обучение

### Архитектура
```python
def create_tfidf_dense_model(input_dim, num_classes=6, dropout_rate=0.3):
    model = Sequential([
        Input(shape=(input_dim,)),
        Dense(256, activation='relu'),
        Dropout(dropout_rate),
        Dense(128, activation='relu'),
        Dropout(dropout_rate),
        Dense(64, activation='relu'),
        Dense(num_classes, activation='softmax')
    ])
    model.compile(optimizer=Adam(learning_rate=1e-4),
                  loss='sparse_categorical_crossentropy',
                  metrics=['accuracy'])
    return model

```
В финальной версии модели для регуляризации используется Dropout=0.3 после первых двух слоев.
Функция потерь - кросс-энтропия. Оптимизация Adam с шагом 1e-4
